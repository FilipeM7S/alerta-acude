# OpenStreetMap water polygons

Raw Overpass API responses (https://overpass-api.de/api/interpreter), fetched 2026-11-14 by `src/geometry.py`.
Each file holds every `natural=water` or `landuse=reservoir` way/relation within 1.5 km of a batch of reservoir reference points, excluding rivers, canals and aquaculture tanks.
